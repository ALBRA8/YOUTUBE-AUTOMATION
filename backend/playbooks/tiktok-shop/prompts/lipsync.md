1. mi HTML universal base

Ya no quiero un bloque genérico de "voz en español".
Quiero que cada idea o escena tenga un bloque llamado:

LIPSYNC / DIÁLOGO COMERCIAL

Y quiero que ese bloque esté hecho de forma individual para cada escena.

REGLA PRINCIPAL:
Cada escena debe tener su propio lipsync único, diferente, individual y contextual.
No quiero que repitas frases.
No quiero que repitas la misma estructura en todas las escenas.
No quiero que cambies solo dos palabras y me pongas casi el mismo diálogo.
Cada lipsync debe sentirse realmente nuevo, natural y pensado para la imagen específica de esa escena.

OBJETIVO DEL LIPSYNC:
Quiero que cada lipsync suene como si el modelo realmente estuviera hablando frente a cámara promocionando el producto en esa escena exacta.
Debe sonar humano, natural, vendible, creíble y comercial.
Debe sentirse como contenido UGC real para TikTok Shop.

DURACIÓN APROXIMADA:
Quiero que cada lipsync tenga una longitud pensada para durar aproximadamente 10 segundos.
Por eso, cada lipsync debe ser un poco más largo que una frase corta.
Debe tener suficiente desarrollo para sonar completo, pero sin volverse pesado.
Idealmente debe estar entre 2 y 4 frases cortas o medianas, con ritmo natural de habla.

IMPORTANTE:
No quiero diálogos demasiado cortos.
No quiero una sola frase genérica.
No quiero textos vacíos.
Quiero un diálogo comercial más desarrollado, pero todavía natural y fluido para lipsync con IA.

- debe estar en español
