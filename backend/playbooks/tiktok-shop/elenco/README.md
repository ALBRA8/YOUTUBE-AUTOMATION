# Elenco TikTok Shop — por campaña

Este nicho NO tiene elenco fijo. Cada campaña aporta:

| Archivo | Quién lo aporta | Uso |
|---|---|---|
| `avatar.png` | usuario | modelo/creador — identidad a preservar en los 6 paneles |
| `producto.png` | usuario | producto real — fidelidad de color, logo, textura |

Colócalos aquí (o adjúntalos directamente en Gemini en la Etapa 1).
La consistencia del modelo es responsabilidad del prompt `prompts/collage.md`,
no de un elenco predefinido.
