LANZADORES ALBRA — DOBLE CLICK Y LISTO
========================================

QUE ES ESTO
-----------
Tres archivos para que ya no tengas que abrir terminal ni escribir
comandos. Todo lo que hace falta ahora es doble click.

ARCHIVOS
--------
1) INICIAR-ALBRA.bat   <- EL QUE VAS A USAR A DIARIO
   Doble click y se encarga de todo:
   - Si el servidor ya esta corriendo -> solo abre el dashboard (no duplica nada)
   - Primera vez: crea el entorno virtual e instala dependencias (tarda mas, es normal)
   - Siguientes veces: arranca en segundos (no reinstala nada)
   - Abre el navegador SOLO cuando el servidor ya responde (adios al error
     "no se puede acceder a este sitio")
   - El servidor corre en su propia ventana: "ALBRA SERVER - NO CERRAR"
     (ahi ves los logs; cerrar esa ventana = apagar el servidor)

2) DETENER-ALBRA.bat
   Doble click y apaga el servidor del puerto 8000 de forma limpia.
   Solo mata procesos de Python, no toca nada mas de tu PC.

3) start.bat
   Se conservo por compatibilidad, pero ahora solo delega en
   INICIAR-ALBRA.bat (mismo resultado).

PRIMERA VEZ — CHECKLIST
-----------------------
[ ] Python 3.11+ instalado con "Add Python to PATH" marcado
    (si INICIAR te dice "Python no encontrado", es esto)
[ ] Carpeta backend\.env configurada:
    copia backend\.env.example como backend\.env y pon tus claves
[ ] Extension "Flow Script Processor" cargada en chrome://extensions
    (carpeta extension/ del proyecto, modo desarrollador)

SI WINDOWS MUESTRA "Proteccion contra virus" AL HACER DOBLE CLICK
-----------------------------------------------------------------
Es el SmartScreen por ser un .bat descargado. Click derecho sobre el
archivo > Propiedades > marca "Desbloquear" > Aceptar. Solo se hace una vez.

PROBLEMAS FRECUENTES
--------------------
- "El servidor no respondio en 120s" -> mira la ventana ALBRA SERVER,
  ahi esta el error real (casi siempre es el .env o un puerto ocupado).
- Ya habia un servidor viejo colgado -> doble click en DETENER-ALBRA.bat
  y vuelve a dar doble click en INICIAR-ALBRA.bat.
- La extension "no ve" el backend -> con el dashboard abierto en el
  navegador, recarga la extension en chrome://extensions.
